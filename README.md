# 1c-spisanie-stoimost

Доработан документ «Списание» типовой конфигурации «1С:Управление нашей фирмой», добавлено отображение стоимости списываемых товаров по актуальной закупочной цене.

Чтобы установить расширение, необходимо запустить информационную базу в режиме Конфигурация, далее выбрать Конфигурация - Расширения конфигурации - Добавить конфигурацию - Действия - Конфигурация - Загрузить конфигурацию из файлов - Выбрать папку с расширением

Чтобы задать необходимую закупочную цену, в константе Закупочная цена нужно указать Вид цены, который в дальнейшем будет использоваться 

Проверить работу доработки можно, создав документ Списание и заполнив все необходимые данные, стоимость рассчитается автоматически
